# 团团 · 浏览器里的陪伴宠物

一个可以通过网页体验的宠物产品原型，支持摸摸头、喂食、休息、小游戏、专注计时、陪伴日记和手动保存记忆。

## 体验说明

- 聊天使用本地预设回应，尚未接入大语言模型。
- 使用数据保存在当前浏览器的本地存储中；换设备或清除浏览器数据后不会同步。
- 网页小窗受浏览器限制，不保证透明背景或始终置顶。

## 部署

所有资源均使用相对路径，适用于 GitHub Pages 的项目站点。在仓库 Settings → Pages 中选择 main 分支、根目录后即可发布。`.nojekyll` 用于直接托管静态资源。

## 本地体验

下载并解压全部文件后，双击 `index.html` 可体验。也可在此目录运行任意本地静态服务器。

## 隐私

发布内容仅包含页面、脚本、样式和宠物图形。不包含桌面应用运行数据、用户对话、账号密钥或 API 配置。
